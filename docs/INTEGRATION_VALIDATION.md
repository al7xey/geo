# Проверка объединения шагов 0-8

Проверка проведена 3 ноября 2026 года на Windows с Python 3.12.10.
Реальные сайты и платные нейросетевые API для проверки не вызывались.

## Сохранность ранних шагов

Код из предоставленного архива перенесён отдельно, без исправления алгоритмов.
Для 89 исходных файлов, включая код и проверки шагов 0-4, а также исходную
конфигурацию зависимостей, сохранены SHA-256. Тест сравнивает точные байты.
Новые сетевые клиенты взамен старых не добавлялись. Числовое закрепление IP,
проверки TLS/peer, robots, бюджеты и защищённый файловый ввод-вывод сохранены.

## Сквозная проверка

В тесте выполняются настоящие функции всех этапов:

1. Шаги 0-1 получают учебную страницу через контролируемый транспорт и создают
   проверенный набор текстов.
2. Исходные функции шага 2 обрабатывают профиль и 40 вопросов, полученных от
   учебного исполнителя, без обращения к публичной модели.
3. Исходный шаг 3 проверяет и сохраняет профиль, вопросы и контрольную сумму.
4. Исходный сборщик шага 4 получает 120 ответов от трёх систем через локальный
   тестовый HTTP-сервер. Одна система намеренно возвращает ошибки.
5. Новая связка выполняет шаги 5-8 и проверяет воспроизводимость файлов.

Проверено: 35 небрендовых и 5 брендовых вопросов; ошибочная система исключается;
для измерения остаются 70 пригодных ответов двух систем на 35 небрендовых вопросов.
Тексты и файлы сбора после обработки не изменяются. На шагах 5-8 сетевые соединения
в тесте запрещены. Дополнительно проверены повторные попытки, порог ровно 20 %,
пропуски по бюджету, неоднозначные сокращения и соответствие доменов с www.

## Проверки реализации

- Общие проверки исходной программы: 723 прошли, 3 пропущены по условиям
  платформы. Дополнительная проверка соответствия доменов с www прошла отдельно
  и входит в 136 проверок установленного пакета. Полный журнал сохраняется
  локально в `private/integration-checks/full-final.xml`.
- Установленный wheel-пакет: 136 проверок шагов 5-8 и передачи 0-4 → 5-8 прошли
  в отдельном окружении с изолированным запуском Python. Подтверждён импорт именно
  установленного пакета, а не исходной папки.
- Ruff для всего src/tests/tools: без ошибок.
- Строгий mypy для Windows и Linux: без ошибок, 77 исходных файлов.
- Bandit для рабочего кода: без проблем. Для инструментов учебных данных
  допускаются проверочные утверждения и воспроизводимая случайная выборка;
  исключения B101/B311 не применяются к рабочему коду целиком.
- Проверки неизменённых схем шагов 0-1 и сборка wheel/архива исходников прошли.
  Сборка содержит обе части: ранние шаги и новую обработку ответов.

В Windows тестам исходного шага 3 нужен режим UTF-8: часть учебных файлов в них
записывается с системной кодировкой. Код шагов 0-4 не менялся. Общая команда
запускает ранние скрипты с `-X utf8`; CI задаёт UTF-8, а локальная общая проверка
также выполнена с `-X utf8`.

На учебном наборе из 120 ответов локальная обработка 5-8 заняла 3,68 секунды,
полная повторная проверка сохранённой цепочки - 0,95 секунды. Это результат
конкретного компьютера и учебных текстов, не обещание такого времени на любом
объёме. Время сбора ответов моделями сюда не включено.

Linux фактически проверяется заданием GitHub Actions; локально проверена
совместимость типов с Linux, а не исполнение на Linux. При очистке старых
временных папок Windows появлялись предупреждения, не связанные с результатом
самих проверок. Эти старые папки не удалялись вручную.

Смысловые проверки нейросетью на шагах 6-8 остаются отключёнными. Их результаты
не подменяются учебными. Неопределённости, неполнота сбора и отсутствие оценки
надёжности видны в выходных файлах. Шаги 9-12 не входят в это объединение.
