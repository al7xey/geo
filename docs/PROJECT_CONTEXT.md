## Фактическое состояние

Репозиторий C:\GEO, Python >=3.12, пакет geo-audit 0.3.2. Реализованы:

- Нормализация без сети, точный scope, локальный полный PSL с private/wildcard/exception.
  Снимок VERSION 2026-10-31_14-17-28_UTC, SHA-256
  617d1b276660e5a01209d7b58159450e400cf636634a7a9c2cfd50a1c6675d01.
- Последовательный async SafeHttpClient: numeric-IP pin и peer перед HTTP, исходные Host/SNI,
  TLS verification, ручные redirects/retries/fallback, Retry-After/pacing, encoded/decoded caps,
  общий deadline. Proxy/env trust/cookies/keepalive/HTTP2 отключены; DNS не кэшируется.
- validate_site с инъекцией config/client/Budget/TimeServices/store; полноценный CLI.
  HTML/JS/barrier/placeholder/empty/binary/incomplete оцениваются с основаниями/confidence.
- Новая приватная папка на run; raw тела и attempt observations, raw/manifest.json,
  journal/config/budget и финальный site.json. Atomic publish, SHA-256, handle-based no-follow
  защита. Отмена сохраняет завершённые наблюдения; программные ошибки не маскируются сетью.
- Step1Input и Step1Handoff: передача готового FetchResult с тем же Budget либо загрузка
  из сохранённой папки с проверкой версий/хронологии/scope/файлов/hash/representations/свежести.
  Loader не обращается к сети, не начинает обход; crawl_permission=unknown.

Полные схемы: schemas/; синтетические примеры: examples/contracts/; генератор выпускает
32 воспроизводимых артефакта. Примеры с фиксированным временем не являются действующим входом.
Сохранён архивный пример 1.0. Полноценная текущая схема 1.2.0, algorithm step0-1.2,
config step0-config-1.2.0 и config_sha256. Смешанные/неизвестные версии отвергаются.
Пакет 0.3.0 завершает ранее закоммиченную, но не принятую оркестрацию 0fa9d78.
